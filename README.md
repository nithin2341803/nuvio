# Nuvio Website

A responsive one-page marketing website for Nuvio, with:
- Nuvio logo from the supplied image
- Hero section and positioning
- Starter / Intermediate / Premium plans
- Process section
- Hunder Travelouges live project
- Review section with clearly marked sample testimonials
- Project registration form
- Automatic WhatsApp message generation to 9037686996

## Run locally
Open `index.html` in a browser, or use any simple static server.

## WhatsApp
The form opens WhatsApp with the submitted details pre-filled. The international WhatsApp number is configured as +91 9037686996.

## Before launch
Replace the sample review cards with genuine client testimonials, and update any pricing/terms that change.
